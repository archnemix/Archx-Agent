# Rough ideas — not approved scope

These are reminders, **not** requirements, designs, or promised features. Revisit with the user when they are ready; do not implement them merely because they appear here.

## 2026-11-09 — Team learning / team building / collaborative AI

The user is considering a future **team learning or team-building mode**. If users choose to store relevant information in the cloud, multiple people could sign in, talk with one another in a group conversation, and work with AI to learn, make new things, or build something together. Group chats in other AI products are a broad inspiration, not a design to copy. The exact experience is still a rough idea and may change.

**To decide later:** whether this is a separate mode or shared capability; what a team can create together; whether cloud storage is optional and what stays local; which conversations, files, memories, and outputs are shared; membership, invitations and roles; consent, permissions, privacy, retention and deletion; account/provider and cost choices. No cloud account, collaboration feature, or data-sharing default has been chosen.

**Status:** Parked for future discussion. The current home-launcher and chat milestones are unchanged.
