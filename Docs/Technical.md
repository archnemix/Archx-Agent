# Technical overview

Iced is the selected Rust desktop UI framework; Windows, macOS, and Linux are first-class targets from the start. The native launcher is implemented, but no AI provider, agent runtime, persistence engine, or product backend has been selected or built. See [Files_Info.json](Files_Info.json) for each file's responsibility and inputs/outputs, [Logic.md](Logic.md) for implemented call flows, and [Plan/Architecture.md](Plan/Architecture.md) for discussed product behavior. Keep these aligned as components are added.

## Home shell in progress

- `Cargo.toml`: Rust 2024 application with Iced 0.14 for native UI and `image` 0.25 PNG support only for opt-in cross-OS screenshot capture. The latest three-app text-hover follow-up passed five focused tests, release builds, Home/About and three synthetic hover-phase captures on each of Linux, Windows, and macOS; Windows CI also verified PE GUI subsystem 2 (no console) and truthful product metadata. See `Test_Results/Unreleased/Gui_Validation.md`. This does not establish future agent functionality or pixel-identical UI rendering.
- `src/main.rs`: initializes the window, Manrope typeface, native window icon, theme, and application callbacks; Windows **release** builds select the GUI subsystem so launching the app does not open a console.
- `src/app.rs`: holds home/about navigation and opt-in `ARCHX_SNAPSHOT` capture state. `ARCHX_SNAPSHOT_PAGE=about` selects About; `ARCHX_SNAPSHOT_HOVER=training|tuning` with `ARCHX_SNAPSHOT_PHASE=0|1|2` freezes a text-card phase for CI captures only. On real hover, a 700ms timer advances one of three conceptual stage highlights and stops on exit/About. Snapshot delay remains five seconds. No model or persistence yet.
- `src/home.rs`: renders the AI Lab launcher, Agent feature and About view; unfinished destinations are inert.
- `src/app_tile.rs`: renders the temporary Agent image and two unavailable text-based model apps. Their clipped 140px panels show a three-stage emphasis on hover, not operational progress; focused tests check three destinations and Agent cover decoding. Model Monitor is hidden.
- `build.rs`: embeds the user-supplied Archnemix ICO and company metadata only on Windows. The metadata is not a digital signature.
- `src/style.rs`: black/grey palette and reusable styles, including a native gradient/shadow selected-menu pill. `assets/fonts/` holds licensed Manrope; `assets/` holds the temporary Agent hero/tile artwork embedded at compile time.
- `.github/workflows/gui.yml`: source-triggered three-OS compilation/test/screenshot review and repository-hosted portable Windows executable. The local sandbox has no Rust toolchain; run `43186966425` supplies three-card build/runtime and synthetic phase evidence. Its still screenshots do not validate physical mouse movement, 3D Agent animation or native window chrome, and the unsigned binary cannot show a verified publisher.
