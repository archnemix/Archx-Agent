# Unreleased test results

Records for validation before the first release are stored here. [`visual/`](visual/README.md) holds screenshots and [`non_visual/`](non_visual/README.md) holds tests, builds and PE checks. [Gui_Validation.md](Gui_Validation.md) summarizes the current cross-platform Iced launcher review and its Windows executable. When a version ships, keep evidence organized by version and retain only the current and previous two versions.
