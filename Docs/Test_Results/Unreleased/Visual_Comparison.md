### Chat chrome rework — GUI run 45256127460

Hands-on feedback identified the native Chat as visually unpolished ("slop") versus the reference. The native Agent chrome was rebuilt on the measured 1.9.0 component system (`Docs/design.md` § *Native adoption of the 1.9.0 component system*): reference dark tokens and the `.btn`/`.mini-toggle`/`.page-nav-btn`/`.model-import-row` style families, Manrope Bold headings, bundled vector glyphs (no text-glyph icons), the brand-mark rail row, white New chat, endpoint badge + privacy-note footer, topbar selector pills with a real connection dot, the monitor-glyph empty state with white primary **Add a provider** and ghost **Open settings**, the mini-toggle + white send/stop composer, the Jump to latest pill, card-structured Settings pages, and reference-style import rows (status dot, ID, `free`/`manual` pills, inline probe badges, drawn 17px checkboxes, white primary import). Presentation only — no provider transport, consent or staging behavior changed.

The refreshed equal-size comparisons ([Chat](visual/reference-vs-native-chat.png) · [Models](visual/reference-vs-native-models.png) · [Import](visual/reference-vs-native-import.png)) pair the unchanged 1.9.0 browser captures with the new 1280×800 Linux captures from this run (regenerate with `scripts/build-comparisons.py`). Reviewed side by side at full size, the shared structure now aligns closely: rail composition, nav rows, New chat, empty-state hierarchy and actions, composer framing, topbar status, and the import dialog's title/toolbar/toggle/rows/footer. Remaining visible differences are mostly **deliberate absences or honest copy**, not styling drift: the web's five destinations, Temp/Select toggles, theme/delete footer icons, profile/system-prompt selectors, Chat debug and the composer's Web tool have no native implementation and are not faked; the empty-state copy states OS-vault/session truth instead of the web's data-area wording; the brand mark is the supplied Archnemix mark, not the web's A logo; the native import rows show fuller bounded probe evidence under probed rows; and Manrope/system-font rasterization still differs. The native send button appears dimmed in fixtures because send is honestly disabled with no draft/model selected.

### Round 3 — color/shade/spacing fidelity — GUI run 45453087902 (current)

The user measured real tonal drift in the chrome rework ("a lot of difference … color shade darkness and so on has different highlighting things") and mandated a systematic pass: every reference/native capture pair split into four quadrants and compared at zoom, backed by pixel sampling and a palette scan against the 1.9.0 `base.css` token table. The audit found **40 issues — 27 color/highlighting and 13 spacing — catalogued with measurements and fixes in [`Quadrant_Color_Audit.md`](Quadrant_Color_Audit.md)**: invented greys (`#333333` borders, `#b2b2b2` secondary text, `#919191` eyebrows, `#7ecf96`/`#e28b8b` status pastels), wrong fill roles (send disabled-grey, ghost text grey, white fills where the web uses a 10% accent wash), scrim opacity 0.78 vs 0.55, loud red failure dots/pills, filled import rows vs transparent on `--bg-2`, Iced's `#5d626d` default scrollbar column, plus rail nav pitch 33 vs 40, oversized New chat, centered vs top-aligned empty state, uneven sub-nav rows and a missing page-head rule.

Every fix copies the reference's exact values (`#000000` is `#000000` on the same screen). The post-fix palette-conformance scan of run 45453087902's captures flags only antialiasing blends at text/fill edges — including `#737373`/`#6e6e6e`, which are the reference's own scrim blends over the white button and appear identically in the reference capture (dimmed white: `255 × 0.45 = 115 = #737373`, sampled equal in both). Verified pairs: scrim `.55`, send always `--accent` white with black icon (the web never greys it), ghost/tiny text `#f4f4f4`, secondary text `#8a8a8a`, borders `#2c2c2c`/`#404040`, selection = accent 10% wash, probe-fail dot `#5c5c5c`, eyebrows accent-white 12px bold, drawn 36×20 switch, `.set-nav` active inset bar, transparent import rows with white IDs, quiet scrollbars on all seven scrollables. Four new regression tests lock the palette, scrim, wash and button-text rules (**65 passed, 0 failed** on Linux, Windows and macOS in this run; platform logs in `non_visual/`). The remaining honest deltas are unchanged from above (missing web features, honest copy, supplied brand mark, Iced's lack of dashed borders/letter-spacing) plus sub-pixel Manrope rasterization. State fixtures only — no live-provider, pointer/scroll, a11y or pixel-identity claim.
