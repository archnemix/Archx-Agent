## Second pass: multi-turn Chat and returned reasoning

The first comparison's single-answer fixture was insufficient to assess a real conversation. A **review-only**, four-turn offline fixture now runs only when `ARCHX_SNAPSHOT_CHAT=conversation-review` is combined with `ARCHX_SNAPSHOT`; the normal Chat starts without these sample messages. It uses two user messages and two assistant replies. The first assistant reply contains only text; the second contains returned reasoning, a heading, inline code, a JavaScript block and a table. These are **not provider responses**. The CI workflow captures a wide view, the default-size view, and a wide view snapped to the end of the scrollable log on each OS. This extra bottom capture matters: at the top of a long response, the table is under the fixed composer, but it is reachable when scrolled—not lost or rendered behind the composer. Do not infer from the static capture that live chat automatically follows new tokens; that interaction was not tested.
