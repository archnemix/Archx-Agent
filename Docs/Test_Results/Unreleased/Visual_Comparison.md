# Native UI comparison against user review captures

Reviewed the archived user references in `internels/reference/ui/user-review-2026-11-16/image-13.png`–`image-23.png` against the **fresh** native captures produced by [GUI run 44126291312](https://github.com/archnemix/Archx-Agent/actions/runs/44126291312). This run passed Linux, Windows, macOS and the separate real Smol Q2_K wrapper job; each GUI runner reported **39 passing regular tests, one ignored opt-in integration test**. The comparison is visual only: captured Chat/reasoning, catalog results and custom endpoint fields are scripted, synthetic fixtures, not evidence of live vendor replies or hands-on acceptance.
