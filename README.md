# Archx AI Lab

Archx AI Lab is the Archnemix desktop entrance for AI/ML work; Archx Agent will be its chat-and-agent area. The first native Iced home-screen build is in progress; model, training, and fine-tuning features are not yet available. Read the [working rules](Docs/Rules.md), [product plan](Docs/Plan/Architecture.md), and [design system](Docs/design.md) before changes.

[Docs/](Docs/README.md) contains project records; [internels/](internels/README.md) is reserved for internal helper material.
