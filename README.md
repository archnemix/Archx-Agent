# Archx AI Lab

Archx AI Lab is a native Rust/Iced launcher with an Archx Agent destination. Chat supports session-only provider/model selection, OS-vault keys, manually added/fetched models, opt-in sending, native Markdown, returned reasoning when supplied, and a default streaming/whole-response choice. Other modes, Training and Fine-tuning remain previews. The Windows GUI executable is unsigned and has no publisher verification; it does not open a console. **Live provider calls and interactive OS-vault journeys have not been validated by CI.** [Download the unsigned Windows build](deliverables/Unreleased/windows/archx-ai-lab.exe), or view the [three-OS validation record](Docs/Test_Results/Unreleased/Gui_Validation.md). Read the [working rules](Docs/Rules.md), [product plan](Docs/Plan/Architecture.md) and [design system](Docs/design.md) before changes.

[Docs/](Docs/README.md) contains project records; [internels/](internels/README.md) is reserved for internal helper material.
