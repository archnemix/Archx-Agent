# Archx Agent — documentation

This directory belongs to the **Archx Agent** app (`apps/archx-agent/`). The
second app keeps its own docs in `apps/training/docs/`; the two never share a
folder, so neither can overwrite the other's records. Repository-wide
orientation lives in the root `README.md`.

- [Rules](Rules.md): working rules; read before making changes.
- [design.md](design.md): AI Lab visual system and cross-OS review criteria.
- [Plan/](Plan/README.md): agreed scope and architecture.
- [Plan/Adding_An_App.md](Plan/Adding_An_App.md): the self-contained guide for
  starting a new app in the Lab — manifest fields, crate wiring, the tests that
  enforce the contract.
- [Roadmap](Roadmap.md): ordered implementation steps once scope is agreed.
- [Thinking](Thinking.md): work-round decisions and problem resolutions.
- [Change](Change.md): user-requested scope changes.
- [Rough ideas](Rough_Ideas.md): uncommitted ideas to revisit later, without expanding the roadmap.
- [Changelog](Changelog.md): changes by release.
- [Technical](Technical.md), [Files_Info.json](Files_Info.json), and [Logic](Logic.md): technical overview, file inventory, and implemented call flows.
- [Workaround](Workaround.md): access and tooling workarounds.
- [Secrets](Secrets.md): GitHub secret names and descriptions, never values.
- [Research.json](Research.json): source-backed research index.
- [Security design](Security_Design.md) and [local provider trial](Provider_Trial.md): threat model, user-run test steps and unverified limits.
- [Test_Results/](Test_Results/README.md): versioned test commands, inputs, and outputs.
