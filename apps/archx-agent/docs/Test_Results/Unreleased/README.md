# Unreleased test results

Records for validation before the first release are stored here. [`visual/`](visual/README.md) holds screenshots and [`non_visual/`](non_visual/README.md) holds tests, builds and PE checks. [Gui_Validation.md](Gui_Validation.md) summarizes the current cross-platform Iced launcher review and its Windows executable.
[What_You_Can_Test.md](What_You_Can_Test.md) is the hands-on counterpart: one row per
reported item, with the control to press and the result to expect. When a version ships, keep evidence organized by version and retain only the current and previous two versions.
