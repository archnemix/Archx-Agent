# Assets

Only resources needed by the desktop UI belong here. [brand/](brand/README.md) contains the user-supplied logo and its native icon derivatives. [fonts/](fonts/README.md) contains the bundled typeface and its license. `agent-cover.png`, `model-training.jpg`, `fine-tuning.jpg`, and `model-monitor.jpg` are original generated monochrome illustrations; `agent-tile.jpg` is a crop of the Agent cover. The four app-tile JPEGs are normalized to 800 × 480 for bounded display. All artwork is embedded in the executable, never fetched at runtime.
