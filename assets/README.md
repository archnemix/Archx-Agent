# Assets

Only resources needed by the desktop UI belong here. [brand/](brand/README.md) contains the user-supplied logo and its native icon derivatives. [fonts/](fonts/README.md) contains the bundled typeface and its license. `agent-cover.png` is the original generated monochrome Agent illustration; `agent-tile.jpg` is a cropped 800 × 480 shelf cover. Both are embedded temporary art until the user approves and supplies an animated Agent model. Model Training and Fine-tuning now use typography rather than bundled image covers; Model Monitor is hidden. No artwork is fetched at runtime.
