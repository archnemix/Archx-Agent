# Assets

Only resources needed by the desktop UI belong here. [brand/](brand/README.md) contains the user-supplied logo and its native icon derivatives. [fonts/](fonts/README.md) contains the bundled typeface and its license. [icons/](icons/README.md) contains the pinned local Lucide navigation glyphs and their license. Agent, Model Training and Fine-tuning now use native typography instead of generated cover images; Agent has distinct kinetic six-mode artwork on its feature and shelf panels. Model Monitor is hidden. The transparent sidebar logo and embedded window icons come from the supplied brand source; no artwork is fetched at runtime.
