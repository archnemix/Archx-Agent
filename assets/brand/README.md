# Archnemix branding

`archnemix-source.png` is the original transparent logo supplied by the user. `archnemix-lockup.png` trims its empty margins and composites it on near-black for the sidebar. `archnemix-icon.png` and `archnemix.ico` are square black-backed crops derived from the same source for native window/taskbar and Windows executable icons. No new trademark or signature is implied by these images.
