# Archnemix branding

`archnemix-source.png` is the original transparent logo supplied by the user. `archnemix-sidebar.png` trims empty transparent margins while keeping its alpha channel; the sidebar displays it at 116 × 116 without a black backing rectangle. `archnemix-icon.png` and `archnemix.ico` remain square black-backed icon derivatives for native window/taskbar and Windows executable icons. No new trademark or signature is implied by these images.
