# Fonts

`Manrope.ttf` is variable [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), used for body/navigation/labels; `OFL.txt` is its unmodified SIL OFL license. `SpaceGrotesk.ttf` is the original variable [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) source (300–700), with unmodified `SpaceGrotesk-OFL.txt`. `SpaceGrotesk-Medium.ttf` and `SpaceGrotesk-SemiBold.ttf` are **static** 500/600-weight instances generated from that source using FontTools varLib.instancer; only these two static instances are registered in Iced. The original variable registration corrupted glyph spacing across the macOS screenshot, including labels elsewhere, so it is retained here as attribution/source but no longer loaded at runtime. All fonts remain under their respective SIL OFL licenses; binaries and verbatim licenses keep their formats without file-purpose comments.
