# Fonts

`Manrope.ttf` is variable [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), used for body/navigation/labels; `OFL.txt` is its unmodified SIL OFL license. `SpaceGrotesk.ttf` is the original variable [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) source (300–700), with unmodified `SpaceGrotesk-OFL.txt`. `SpaceGrotesk-Medium.ttf` and `SpaceGrotesk-SemiBold.ttf` are **static** 500/600-weight instances generated from that source using FontTools varLib.instancer; these static instances are registered in Iced on Linux/Windows only. On the macOS runner, glyph spacing distorted in trials with the variable source, with static instances, **and even with Manrope alone while explicit Medium/Semibold weights remained**. The isolated working fallback registers only Manrope and requests only its Normal weight (size hierarchy only); the precise renderer cause has not been proven. The original Space Grotesk variable font is retained for provenance but never loaded at runtime. All fonts remain under their respective SIL OFL licenses; binaries and verbatim licenses keep their formats without file-purpose comments.
