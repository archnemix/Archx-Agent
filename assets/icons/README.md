# Navigation icons

Six 24×24 Lucide SVG outlines are bundled for the native Iced navigation rail: `house`, `message-circle`, `info`, `settings-2`, `panel-left-open`, and `panel-left-close`. Source: <https://github.com/lucide-icons/lucide/tree/55782beff3a0133df79c417eb68f96e8f19e2404/icons>. Each SVG has only a file-purpose XML comment prepended; geometry is unchanged. The upstream combined ISC/MIT text is retained verbatim in [LICENSE](LICENSE). Assets are loaded from compiled bytes, never from a network endpoint. The user-supplied Archnemix mark, not these icons, remains the product identity.
