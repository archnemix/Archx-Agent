# Navigation icons

Twelve 24×24 SVG outlines are bundled for the native Iced navigation rails and Agent chrome:

- From **Lucide** (upstream combined ISC/MIT text in [LICENSE](LICENSE), source: <https://github.com/lucide-icons/lucide/tree/55782beff3a0133df79c417eb68f96e8f19e2404/icons>): `house`, `message-circle`, `info`, `settings-2`, `panel-left-open`, `panel-left-close`, `chevron-down`, `plus`.
- **Recreated from the MIT-licensed Archx Agent 1.9.0 reference** (`internels/reference/web/archx-agent/public/index.html`, same inline path data): `monitor`, `send`, `stop`, `arrow-down`, `message-square`, `lock`.

Each SVG has only a file-purpose XML comment prepended; geometry is unchanged from its source. Assets are loaded from compiled bytes, never from a network endpoint. The user-supplied Archnemix mark, not these icons, remains the product identity.
