    Research

    A plan that names its author, sources it actually read, citations it re-checks. No crawler and no web search: it reads the URLs you give it.

    New research run

    Archx does not crawl and has no web search: it reads the URLs you paste here (through net.fetch, which needs a grant) and documents in your tool roots. No experiments run in this mode — that is M32.

    A web run asks for net.fetch; refusing it fails the run honestly.

      Learning

      Goals with criteria, a hint ladder you have to climb, and a schedule that shows its arithmetic.

        New goal

        Pick a goal, or create one. A goal is a record: its items, attempts and sessions are rows the CLI reads too.

        Voice and media

        What a file is, measured from its own bytes. The name is kept as a claim, and a .png that is really a JPEG is recorded as both. This build has no speech model, so asking it to hear or speak is refused with every reason named.

          Measure a file

          A path inside the tool roots. Reads the header and hashes the bytes; needs fs.read.

          Say something

          Asks for speech. This build answers with the reasons it cannot, and records the attempt.

          Pick a file, or measure one. The numbers here are read from the file's bytes; a transcript says who wrote it.

          Datasets

          Candidates measured, cleaning that keeps its reasons, splits that do not move, and a manifest you can re-check. A file removed by a rule stays on the record with the rule named.

            Create a dataset

            One source path per line, inside the tool roots. An unstated license is recorded as unknown.

            Pick a dataset, or create one. Every step is a row: what went in, what came out, and why.

            Training

            Two trainers that actually run here - an n-gram language model scored by perplexity, and a nearest-centroid classifier scored by accuracy - and a fine-tune that is refused by name: no weights, no GPU, no library. Nothing on this page predicts a metric it did not measure.

              Run a trainer

              On a built dataset with a split. A fine-tune method is accepted and then refused, with every reason listed.

              Pick a run. The metrics are rows, the artifact is a file with a hash, and a refusal is a row too.

              Remote

              A bundle carries the corpus and its digests, an endpoint computes a result, and the artifact's hash is re-checked here before anything calls it verified. Nothing leaves this machine until the job is approved, and a dispatch that never arrived is a row, not a stack trace.

                Bundle a dataset

                One JSON document: the records, their digests, the manifest checksum and the declared run.

                Pick a job. The bundle hash is recorded before the dispatch, and the artifact is hashed twice on the way back.

                Scenes

                Measured meshes. Wireframe previews are not Blender renders.

                  Select a scene to inspect its geometry.

                  Execution

                  Run a command in a container, in WSL, in a VM or on another machine - and see, on every row, where it ran. A backend that this machine cannot use is listed with the reason rather than hidden, and the project can be sent there and pulled back with a hash per file.

                    Run a command

                    On the chosen target. A backend that cannot run here refuses and records why.

                    Pick a run. The invocation that executed is on the row, not just the command you typed.

                    Search

                    One query across conversations, memory, tasks, workflows, projects, artifacts, tools and files.

                    Code

                    Edit, run and test a directory. Every read, write and command goes through the permission centre, and the runner keeps the ledger.

                      Open a session

                      A session is a directory inside the tool roots. Leave the path empty for the first root.

                      Pick a session, or open one. A write needs fs.write and a command needs shell.run: without a grant the page offers you the approval, and nothing happens until you decide.

                      Experiments

                      Run a declared command with declared parameters, keep the numbers, and compare the runs. A metric is only shown if the experiment said where it comes from.

                        Declare an experiment

                        A command with {placeholder} parameters, and where the numbers come from.

                        Pick an experiment, or declare one. A run needs shell.run, and a metrics file needs fs.read: without a grant the page offers you the approval, and nothing happens until you decide.

                        Play
